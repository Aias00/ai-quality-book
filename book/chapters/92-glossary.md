# 附录 C：术语与保证边界

| 术语 | 本书含义 |
| --- | --- |
| 任务验收 | 根据真实产物、结构化事实与证据判断目标是否满足 |
| 表达合同 | 本实验非空消息和约定数值出现性检查；不是完整语言质量 |
| 校准 | 在有独立参考判断的固定反例上检查评分器误判 |
| 配对 | 同一任务在相同参考与评分条件下保留两边候选结果 |
| 项目组 | 两种任务共享的构造项目，统计时作为重采样单位 |
| 估计对象 | 本书采用项目等权的任务成功差值均值 |
| 百分位区间 | 重采样经验分布的指定分位数；不是模型自评置信度 |
| unknown | 缺少完整输出或用量证据，不能当作正常评分或零消耗 |
| 验收切分 | 程序按清单隔离的任务分组；公开教学题不是秘密基准 |
| 人工裁决 | 对具体报告中表达争议追加决定，不覆盖产物事实 |
| 发布门槛 | 事先规定的完整性、安全、回归与区间检查政策 |
| 指纹 | 字节哈希，用于发现变化；不提供身份认证与签署授权 |

本书没有训练模型、调用真实模型服务或验证其 token 计费，没有 OS 沙箱、生产身份系统、多节点评测服务、不可篡改审计或真实人工研究。实验验证的是公开、受控、合作式实现中的列明行为。
